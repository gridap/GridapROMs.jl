GridapROMs.Utils

GridapROMs.Utils — Module
module Utils

Foundational utilities for GridapROMs, providing:

  • Performance tracking — CostTracker, RBPerformanceTracker, Speedup, compute_error, compute_relative_error.
  • Partial derivatives — PartialDerivative, ∂₁, ∂₂, ∂₃.
  • Contributions — Contribution, ArrayContribution: values indexed by triangulation.
  • Integration domains — FEDomains, Bundle, OperatorType, get_polynomial_order.

GridapROMs.Utils.ContributionTuple — Type
struct ContributionTuple{A,T<:Tuple{Vararg{A}}}
  tuple::T
end

Concrete wrapper around a (possibly heterogeneous) tuple of Contributions (e.g. one per time derivative order in unsteady settings, as in ArrayContributionTuple). A is a common supertype of the elements of tuple, allowing e.g. different jacobian terms to have differently-shaped bases.
