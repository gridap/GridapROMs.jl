GridapROMs.ParamSteady

GridapROMs.ParamSteady — Module
module ParamSteady

Parametric FE operators and solvers for steady parametric PDEs.

Extends Gridap's FEOperator/FESpaces layer with parameter awareness, so that residuals and Jacobians can be evaluated at a Realisation (a batch of parameter samples). The module introduces:

  • Operator types — LinearParamEq, NonlinearParamEq, LinearNonlinearParamEq tag whether a parametric operator is linear, nonlinear, or a split linear + nonlinear combination.
  • Low-level algebraic operators — ParamOperator, LinearParamOperator, LinearNonlinearParamOperator wrap assembled matrices/vectors and expose the residual!/jacobian! interface at parameter level.
  • FE-level operators — ParamFEOperator, LinearParamFEOperator manage Gridap assemblers, FE domains, and parameter-to-sample dispatch. A linear + nonlinear split operator is just a ParamFEOperator (O=LinearNonlinearParamEq) whose res/jac/domains fields are each a Bundle of the linear and nonlinear halves; get_linear_part/get_nonlinear_part split it back apart.
  • Solvers — thin wrappers in ParamFESolvers.jl dispatch parametric solves to the underlying Gridap / GridapSolvers linear or nonlinear solvers.

Downstream modules (ParamODEs, RBSteady, Extensions) all build on the abstractions defined here.

GridapROMs.ParamSteady.ParamFEOperator — Type
abstract type ParamFEOperator{O<:UnEvalOperatorType} <: FEOperator end

Parametric extension of a FEOperator in Gridap. Compared to a standard FEOperator, there are the following novelties:

  • a ParamSpace is provided, so that parametric realisations can be extracted directly from the ParamFEOperator
  • a function representing a norm matrix is provided, so that errors in the desired norm can be automatically computed

Subtypes:

  • ParamFEOpFromWeakForm
  • TransientParamFEOperator

GridapROMs.ParamSteady.ParamOperator — Method
ParamOperator(res,jac,pspace,trial,test[,domains]) -> ParamOperator

Nonlinear parametric algebraic operator, built from the residual res(μ,u,v), the Jacobian jac(μ,u,du,v), a ParamSpace pspace, the trial and test spaces, and optionally the FEDomains on which res and jac are integrated. GridapROMs.ParamSteady.LinearParamFEOperator — Method
LinearParamFEOperator(rhs::Function,jac::Function,pspace,trial,test,args...
  ) -> ParamFEOperator{LinearParamEq}

Returns a linear parametric FE operator. Unlike ParamFEOperator, which takes a residual res(μ,u,v), this takes the right-hand side rhs(μ,v) directly: a genuinely linear problem has no residual to evaluate at a current state u, only a (μ-dependent, but not u-dependent) jacobian and right-hand side. Assembling allocate_residual/residual! on the resulting operator therefore just assembles rhs(μ,v), and solving accounts for the sign accordingly (see ParamSolvers)
