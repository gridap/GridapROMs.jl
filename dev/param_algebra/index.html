GridapROMs.ParamAlgebra

GridapROMs.ParamAlgebra — Module
module ParamAlgebra

Algebraic infrastructure for parametric operators and solvers.

  • NonlinearParamOperator — abstract parametric nonlinear operator; residual and Jacobian are assembled for all parameter values simultaneously.
  • GenericParamNonlinearOperator — generic concrete implementation.
  • ParamCache / SystemCache — caches for operator evaluations (residuals and Jacobians).
  • Solver extensions: solve! overloads for LinearSolver and NewtonSolver acting on parametric operators.

struct LinNonlinParamOperator{A,B} <: NonlinearParamOperator
  op_linear::A
  op_nonlinear::B
  cache_linear::AbstractParamCache
end

Interface that allows to split the linear part of a parametric, nonlinear, differential operator from the nonlinear part. Fields:

  • op_linear: linear part of the operator
  • op_nonlinear: nonlinear part of the operator
  • cache_linear: cache related to the linear part of the operator
